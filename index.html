ARCHITECTURE & CONTEXT

What is POOKALAM.EXE?

POOKALAM.EXE is a deterministic generative-art engine that constructs authentic Kerala ceremonial floral Pookalams using pure JavaScript, SVG geometry, and radial mathematics.

100% Genuine Code

No pre-rendered raster images, cropped photos, or traced assets. Every petal, blossom, and leaf is procedurally computed at runtime.

Deterministic PRNG

A seed hashing algorithm produces consistent, reproducible radial compositions with curated ceremonial color palettes.

Trigonometric Alignment

Uses polar angle division, Cartesian projections, and chord length calculations ($c = 2r \sin(\pi/n)$) for disciplined floral spacing.

Organic Bloom Engine

Choreographed radial flower opening with separated placement and animation transform hierarchies.
