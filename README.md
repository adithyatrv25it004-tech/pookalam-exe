# 🌼 POOKALAM.EXE

> **A programmable celebration of Onam — where Kerala's ritual floral tradition meets generative geometry and procedural creative coding.**

---

## Overview

**POOKALAM.EXE** is a deterministic, browser-based generative art tool and interactive digital installation that constructs complex Kerala floral Pookalams using pure mathematics, HTML5, CSS3, vanilla JavaScript ES modules, and SVG.

Every floral motif, marigold rosette, lotus petal, directional leaf, star accent, and ceremonial border crown is generated procedurally from code at runtime.

## Visual & Functional Highlights

### 1. Dominant Central Artwork Stage
- High-density SVG canvas (1000×1000 viewBox) taking ~75% of visual prominence.
- 8 ceremonial concentric zones from the sacred center jewel to the outer border crown.
- Over 350–500 procedurally generated geometric flower motifs per design.
- Separated transform hierarchy ensuring pristine petal alignment during and after bloom animations.

### 2. Interactive Left Column (Controls & Algorithm)
- **Deterministic Seed Input**: Input custom seeds (e.g. `ONAM-2026`) or click the dice button to randomize.
- **`✨ GENERATE NEW`**: Creates a fresh seed, calculates geometry, updates metadata, and plays a warm Web Audio pentatonic chime.
- **`↻ REPLAY BLOOM`**: Replays the organic center-outward blossom choreography without altering seed or geometry.
- **The Algorithm Card**: Visualizes polar angle ($\theta_i = \phi + i \times \frac{360^\circ}{n}$), Cartesian coordinates ($x_i, y_i$), and chord spacing ($c = 2r \sin(\frac{\pi}{n})$).
- **`⚙️ GEOMETRY VISUALIZER`**: Interactive step-by-step modal showing how mathematics builds floral rings.

### 3. Dynamic Pattern Structure (Layers Legend)
- Live list reflecting the exact layers generated by the current seed.
- **Interactive Layer Hover**: Hovering or focusing any layer dims other layers to 22% opacity and highlights the selected ring.
- **Layer Locking**: Clicking a layer locks isolation focus for detailed inspection.

### 4. Bottom Status Bar & Export
- **Live Status Indicator**: Real-time bloom state (`● Blooming...` → `● Bloom complete 2.14s` with measured timing).
- **Metadata**: Live seed value, layer count, motif count, symmetry multiplier, and SVG dimensions.
- **`💾 SAVE SVG`**: Exports standalone, self-contained SVG files with embedded styles and XML headers.

### 5. Header Utilities & Theme System
- **Info Modal `(i)`**: Project context, competition architecture, and technical details.
- **Web Audio Sound `(🔊/🔇)`**: Synthesized warm chimes and harmonic bloom tones (no external audio files needed).
- **Theme Toggle `(🌙/☀️)`**: Switch between *Night Emerald* (#06120c) and *Kasavu Ivory Light* (#faf7ef).

## Running Locally

Because POOKALAM.EXE uses ES modules, serve it using any static HTTP server:

```bash
# Python
python -m http.server 8000

# Node / npx
npx serve .
```

Open `http://localhost:8000` in any modern web browser.
